# Medical Image Enhancement

A web-based application for enhancing medical images using image processing techniques.
The project focuses on improving image clarity, contrast, and visibility to assist in better visual analysis of medical scans.

## Features

* Upload medical images directly from the browser
* Image enhancement and preprocessing
* Contrast improvement
* Noise reduction
* Real-time preview
* Simple and responsive UI
* Works completely on the client side



## Project Goal

The goal of this project is to explore how digital image processing can improve the quality of medical images and make them easier to analyze visually.

## Future Improvements

* DICOM file support
* AI-based enhancement
* Histogram visualization
* Before/After comparison slider
* Advanced medical filters
* Export enhanced images
